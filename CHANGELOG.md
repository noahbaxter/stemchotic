# Changelog

User-facing release notes, one section per version. The release workflow
publishes the matching `## <version>` section as the GitHub release notes.
Keep entries short and plain, and only list things a user actually sees or
notices. No internals (build, CI, tests, refactors).

## 0.9.4
- RTX 50-series GPUs now work.
- New Compute setting to switch between GPU and CPU.
- Output settings and per-instrument model picks now persist between launches.
